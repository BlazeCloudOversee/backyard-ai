## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Character Library** | Hundreds of community-crafted AI personas ready to download and use |
| **Fully Local** | Models run on your GPU or CPU — nothing is sent to the cloud |
| **Custom Personas** | Build your own AI characters with custom system prompts and personalities |
| **GGUF Compatible** | Works with the entire ecosystem of GGUF-format language models |
